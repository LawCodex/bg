# Bulgaria — legislation as Markdown (LawCodex)

Consolidated (current, in-force) texts of Bulgarian legislation, converted to Markdown, one file
per act. Work in progress — counts are filled in when the first full run completes.

Source: **АПИС — legislation.apis.bg** (free public portal of consolidated legislation run by
the legal publisher АПИС ЕООД). This is **not an official source**: Bulgaria has no official
consolidated-legislation database; the only official publication is the State Gazette
(*Държавен вестник*, https://dv.parliament.bg), which publishes acts and amendments as adopted.
